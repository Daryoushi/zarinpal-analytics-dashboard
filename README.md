# داشبورد تحلیلی و بینش‌پژوهی پذیرندگان زرین‌پال
### پلتفرم وب هوشمند برای تبدیل داده‌های ۲.۲ میلیون تراکنش به تصمیمات مالی و اقدامات اجرایی

---

## ۱. خلاصه اجرایی و دستاوردها (Executive Summary)

این محصول، یک سامانه تحلیلی وب مدرن، تعاملی و فارسی است که با پردازش عمیق **۲,۲۱۳,۲۸۹ رکورد تراکنش واقعی** پذیرندگان زرین‌پال، بینش‌هایی با اثر ریالی مشخص و قابلیت ردیابی کامل به همراه آزمون‌های آماری و کنترل متغیرهای مخدوش‌کننده به پذیرنده ارائه می‌دهد.

### ویژگی‌های کلیدی در یک نگاه:
- **بینش‌های اقدام‌پذیر (Actionable Insights):** هر کارت تحلیل به یک عدد مشخص مالی + پیشنهاد اجرایی ختم می‌شود.
- **شفافیت و ردیابی ۱۰۰٪ (Full Traceability):** با کلیک روی هر عدد، مودال فرمول ریاضی، مقادیر جایگذاری‌شده، فیلتر دیتابیس و نمونه ردیف‌های خام باز می‌شود.
- **تحلیل چندمرحله‌ای و کنترل مخدوش‌کننده:** تفکیک اثر فصلی عید از افت پذیرنده با روش تفاضل در تفاضل (DiD) و کنترل سوگیری انتخاب (Selection Bias) در تحلیل تلاش مجدد.
- **شبیه‌ساز رشد درآمد تعاملی (Live Revenue Simulator):** پیش‌بینی لحظه‌ای اثر ریالی تغییر نرخ بازگشت، ریکاوری درگاه و کاهش پرش.
- **دستیار هوشمند ایزوله (Grounded AI Copilot):** پاسخ‌گویی به زبان طبیعی صرفاً بر پایه داده‌های محاسبه‌شده همان پذیرنده بدون خطای Hallucination یا نشت داده.

## 2. راهنمای اجرای سریع پروژه (Quickstart Guide)

### پیش‌نیازها:
- پایتون نسخه ۳.۱۰ یا بالاتر

### گام اول: نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### گام دوم: اجرای سرور
```bash
python run_server.py
```

### گام سوم: مشاهده در مرورگر
مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

*(مستندات تعاملی Swagger API نیز در آدرس `http://127.0.0.1:8000/docs` در دسترس است).*

## 3. معماری و ساختار پوشه‌ها

```
zarinpal-analytics/
├── backend/
│   ├── main.py                 # اپلیکیشن FastAPI و روترهای REST
│   ├── engine.py               # موتور تحلیلی و شبیه‌ساز مالی
│   ├── ai_agent.py             # دستیار هوشمند ایزوله شده (Grounded AI)
│   ├── models.py               # مدل‌های داده Pydantic
│   └── data/                   # کش‌های ساختاریافته تحلیلی (DuckDB precomputed)
├── docs/
│   ├── eda-findings.md         # مستند کامل گزارش کاوش عمیق داده (فاز صفر)
│   └── eda_stats.json          # داده‌های آماری استخراج‌شده از ۲.۲M رکورد
├── static/
│   ├── css/style.css           # استایل‌های مدرن با فونت وزیرمتن و Glassmorphism
│   ├── js/app.js               # تعاملات کلاینت، چارت‌ها، شبیه‌ساز زنده و مودال ردیابی
│   └── index.html              # رابط کاربری یکپارچه و واکنش‌گرا
├── scripts/
│   ├── precompute_cache.py     # اسکریپت استخراج شاخص‌ها با DuckDB
│   └── inspect_keys.py         # ابزار بررسی اصناف و کدهای پذیرنده
├── test_e2e.py                 # تست‌های خودکار یکپارچگی و سلامت سامانه
├── run_server.py               # لانچر سریع سرور
├── requirements.txt            # کتابخانه‌های پایتون
└── README.md                   # مستندات پروژه
```
